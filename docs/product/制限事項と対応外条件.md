# 制限事項と対応外条件

最終更新: 2026-10-29

本製品は、確認済み条件だけを変換する限定MVPです。

## 変換を停止する条件

- 入力形式とCompanySettingが一致しない
- 科目・補助科目mappingが未確認、stale、親科目不一致
- Tax Contextまたはtax mappingが未確認
- exactな実機Evidenceがない税・仕訳構成
- 保持方法が未確認のoptional field
- Human replacementのない長文・非保持文字
- CP932、列数、日付、貸借等のvalidation error

## 現在の主な制約

- MF 482件full batchは未検証shape 2件のためBLOCK
- 1D2C ×1、10D9C ×1はexact Evidence未取得
- 10D9Cは19 journal sides、10 physical rows
- 対象外仕入、課税売上10%、非課税仕入、非課税売上はexact Evidence取得待ち
- JDL IBEX 出納帳35.5の補助名称は10文字上限。長い入力元名称はHuman-confirmed short-name mappingが必要
- 実機結果を別製品、別version、別Tax Contextへ一般化しない

## 行わないこと

- fuzzy matchやaccount code推測による自動確定
- 補助科目のsilent parent-only化
- optional fieldのsilent drop
- 摘要の自動truncate・要約・文字置換
- unsupported shapeの単純化や推測分割
- BLOCK仕訳だけを除外するpartial output
- 入力変更、既存出力の上書き

Humanが解決できるmappingと、システム側のEvidence・実装待ちは別です。後者を「確認しました」だけでREADYにしません。
