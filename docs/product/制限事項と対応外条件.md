# 制限事項と対応外条件

本製品は、確認済み条件だけを安全に変換する限定MVPです。

## 変換を停止する主な条件

- 入力形式が登録済みCompanySettingと一致しない
- 科目または補助科目mappingが未確認、古い、親科目不一致
- 税Contextまたは税mappingが未確認
- 実機Evidenceの対象外となる税・仕訳構成
- 未対応の複合仕訳shape
- 取引先、tag、memo、invoice、部門などの保持方法が未確認
- 摘要がJDLの制限を超え、Human replacementがない
- JDL科目一覧や税設定が変更され、確認済み条件がstale
- CP932で表現できない文字、列数・日付・貸借などのvalidation error

## 行わないこと

- あいまいな科目を自動確定する
- 補助科目を黙って親科目へ落とす
- optional fieldを黙って削除する
- 摘要を自動で切り詰める、要約する
- unsupported仕訳を単純仕訳へ潰す
- BLOCKした仕訳だけ除外してpartial outputを作る
- 既存ファイルを上書きする

## 対応範囲の注意

JDL IBEX 出納帳35.5で確認した結果を、別製品、別version、別会社設定へ自動的に一般化しません。MF→JDLの95.02%も対象baselineに対するEvidence coverageであり、任意のMF CSVの成功率ではありません。

MF 482件baselineの残24件は、現在未検証の1D2C、10D9C、2D1C、2D3C、4D6C、5D7C、5D8Cのtax combinationです。shape単体のEvidenceがあっても、taxとの組合せが未確認ならBLOCKします。

READY-only候補抽出はformal READY判定ではありません。Windowsに保存されたCompanySettingのmapping、JDL master、tax context、Evidence freshnessを使ったpreflightが最終判定です。
