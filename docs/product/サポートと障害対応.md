# サポートと障害対応

## 問い合わせ時に用意するもの

- app version
- 入力元と出力先
- 仕訳数と確認件数
- readiness状態とerror category
- 「診断情報をコピー」で得たprivacy-safeな内容
- 発生手順
- `application.log`の該当時刻付近

診断情報には会社名、実科目名、補助名、摘要、金額、取引先名、raw CSV、full pathを含めません。実CSVを送る前に必ず送付範囲を合意します。

## 障害時の手順

1. 同じ操作を繰り返す前に、表示内容と時刻を記録します。
2. 診断情報とapplication.logを取得します。
3. JDLへ一部Importされた可能性があれば追加Importを止めます。
4. 必要に応じてJDLをbackupから復元します。
5. 原因修正後、既存outputを上書きせず別pathへ再生成します。
6. 件数、貸借、主要項目を再確認してからretryします。

## 復元とretry

アプリのformal outputはatomicですが、JDL側のImport後操作は別管理です。backup、対象期間、Import件数を記録し、重複Importを防ぎます。原因不明のままCSVを手修正して通すことはしません。
