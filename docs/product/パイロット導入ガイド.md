# パイロット導入ガイド

## 開始前のMUST

- 対象ソフト・version・会社・会計期間を確定する
- 実際のImport先から最新JDL科目一覧を取得する
- 元CSVとJDL会社のbackupを保存する
- CompanySettingを作成し、BLOCK=0を確認する
- 仕訳数、物理行数、貸借、出力期間の期待値を記録する
- retry用に未使用の出力pathを用意する
- 問い合わせ担当と復元担当を決める

## Test Import

初回は対象範囲を合意し、可能なら複製・test環境または安全に復元できる状態でImportします。Import後に件数、貸借、代表仕訳、補助、税、摘要を確認します。同期間を再Exportできる場合はstrict comparisonを行います。

## Go / No-Go

**Go**: READY、atomic output、期待件数一致、貸借一致、主要項目一致、復元・retry手順確認済み。

**No-Go**: 手修正、silent skip、原因不明の差分、未確認mapping、backupなし、対象外version・形式。

## Pilot中に記録すること

- 初回設定時間と次回変換時間
- 新規確認件数
- BLOCK理由と解消方法
- Import・再Export結果
- support対応時間
- 保存済み設定が翌月も再利用できたか

最初は父親事務所内で同じ手順を2回以上再現し、その後1～3社の限定有料pilotへ進みます。
