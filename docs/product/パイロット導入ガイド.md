# パイロット導入ガイド（Money Forward → JDL）

最終更新: 2026-10-31

初めて使う事務所の方が、1社分の仕訳を JDL に取り込むまでの手順です。細かい画面の説明は [操作ガイド](操作ガイド.md)、困ったときは [サポートと障害対応](サポートと障害対応.md) を見てください。

## 始める前に（必須）

- [ ] 対象の会社と会計期間を決める。期をまたぐ場合は期ごとに分ける
- [ ] JDL の対象会社の**バックアップ**を取る（取込で問題があったときに戻すため）
- [ ] JDL 側の対象期間に、テスト用の仕訳などが入っていないことを確認する
- [ ] アプリの「診断情報をコピー」に表示される Build identifier を控える（問い合わせ時に使う）
- [ ] 困ったときの連絡先を確認する（パイロット開始時にご案内）

## 1. Money Forward から仕訳帳 CSV を出す

Money Forward クラウド会計の仕訳帳から、対象期間の CSV をエクスポートします（19項目の仕訳帳 CSV）。ファイルは開いて編集せず、そのまま使います。

## 2. JDL の科目一覧を用意する

取込先の JDL 会社から、科目一覧（補助科目を含む）を PDF で出力します。別の会社の科目一覧は使えません。科目や補助を追加・変更したら、新しい一覧を読み込み直します。

## 3. アプリに会社を設定する

1. 「会社を追加」し、入力元に Money Forward、変換先に JDL を選びます
2. 手順2の科目一覧 PDF を読み込みます
3. JDL の税設定（課税／税抜・税込／原則・簡易／個別対応・一括比例配分）を JDL の画面と見比べて選び、「確認しました」を付けて保存します

## 4. 確認が必要な項目を確認する（初回のみ）

CSV を選ぶと、確認が必要な項目だけが表示されます。

| 画面 | 確認すること |
|---|---|
| 科目・補助科目 | MF の科目が JDL のどの科目・補助になるか。補助がない仕訳を、JDL のどの補助にまとめるか |
| 税区分 | MF の税区分を JDL でどう扱うか（実機で確認済みの候補が表示されます） |
| 摘要 | JDL に入らない摘要（32文字超・改行入りなど）の置き換え文。同じ摘要は1回の確認で全仕訳に適用されます |
| 取引先 | 取引先名を摘要に残すかどうか |

「システム側の確認待ち」と表示されたものは、事務所の確認では解消しません。診断情報をコピーしてご連絡ください。

## 5. JDL 用 CSV を作る

状態が「変換できます」になったら、元の CSV とは別の保存先を選んで変換します。表示される仕訳数・行数・期間を控えます。

## 6. JDL に取り込む

1. JDL のバックアップがあることを確認します
2. 作成した CSV を、控えた期間で JDL に取り込みます
3. 取込件数、貸借の合計、代表的な仕訳（複合仕訳・補助・税区分・摘要）を確認します
4. パイロットでは、同じ期間を JDL から書き出してお送りください。こちらで元の変換結果と1行ずつ照合します

## 翌月以降

新しい CSV を選ぶと、新しく出てきた科目や摘要だけが確認対象になります。

## 止まったとき・おかしいとき

- CSV を手で直して取り込まないでください
- 「診断情報をコピー」の内容と、表示されたメッセージを保存してご連絡ください（会社名・金額などは含まれません）
- JDL に一部だけ取り込まれた可能性があれば、追加で取り込まずバックアップへ戻してください

## パイロットで記録すること

| 項目 | 目的 |
|---|---|
| 仕訳数・物理行数・期間 | 規模 |
| 確認が必要だった項目数（科目・補助・税・摘要） | 初回の手間 |
| 初回設定と確認にかかった時間 | 価格と導入支援の量の根拠 |
| 変換・取込にかかった時間、従来の作業時間 | 削減効果 |
| 止まった理由と件数（事務所の確認／システム側） | 対応範囲の広げ方 |
| JDL 取込の成否、照合結果 | 品質 |
| 問い合わせの内容と回数 | サポートの負荷 |
| 翌月も使ったか、そのときの確認件数 | 継続利用 |

## Go / No-Go

- **Go**: 「変換できます」、期待した件数・貸借が一致、代表仕訳が一致、バックアップあり
- **No-Go**: CSV の手修正が必要、原因不明の差分、未確認の項目、バックアップなし、対象外の JDL 製品・版
