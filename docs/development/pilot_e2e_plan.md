## 2. BLOCKを黙って除外しない仕組み
弥生の正式変換は全体単位（1件でもBLOCKなら入力全体が変換不可、何も出力しない）。READYだけを自動で選んで出力する経路は弥生には無い（MFのみ `moneyforward_ready_batch`）。Pilotは、BLOCKが無い期間を**弥生側で期間指定して出し直し**、その入力全体がREADYであることで対象を限定する。除外した期間の仕訳は、全体2,514仕訳との差として件数を突き合わせ、Pilot記録に残す。
