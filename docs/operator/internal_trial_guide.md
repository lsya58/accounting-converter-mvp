# 会計データ変換 内部試用版 ご利用の手引き

この試用版は、弥生会計・Money Forwardの仕訳データを、JDL IBEX 出納帳 35.5 に取り込める
CSVへ変換するWindowsアプリです。今回の試用では、**変換の前に必要な会計判断（科目・補助科目・
税区分・摘要などの対応）を、画面で無理なく行えるか**を評価していただきます。

> **大切なお願い**
> - 作成したCSVを **JDLの本番環境へ取り込まないでください**。本番への取込は、検証用の会社での確認が終わってから、別途ご案内します。
> - アプリが候補を表示しても、**確定するのは人の確認だけ**です。候補が正しいとは限りません。
> - 顧客のデータや画面の写真を、メール・チャット・クラウドなど外部のサービスへ送らないでください。

---

## 1. インストール

1. 受け取ったZIPファイル（`AccountingConverter_InternalTrial.zip`）を、デスクトップなど分かりやすい場所に保存します。
2. ZIPを右クリック →「すべて展開」を選びます。
3. 展開してできた `AccountingConverter` フォルダの中の **`AccountingConverter.exe`** をダブルクリックすると起動します。
   - フォルダの中の `_internal` は動作に必要です。削除・移動しないでください。exeだけを別の場所へコピーしても動きません。
   - インストーラーはありません。不要になったらフォルダごと削除できます。

**警告が表示された場合**
「WindowsによってPCが保護されました」などの警告が出たら、**そのまま実行せず**、開発担当者へご連絡ください。
試用版は電子署名をしていないため表示されることがあります。ウイルス対策ソフトの停止や除外設定はしないでください。

## 2. 初回の準備（会社ごとに1回）

1. アプリ上部の「会社を追加」を押します。
2. **会社名**を入力します（アプリの中で区別するための名前です）。
3. **入力元**を選びます（弥生 / Money Forward / JDL）。弥生の場合は、その会社の仕訳データ（CSV / TXT）を1つ選びます。形式の判定に使います。
4. **JDL科目一覧**として、その会社のJDLから印刷した科目一覧のPDFを読み込みます。
5. 内容を確認して保存します。

会社の設定はこのPCの中（`%LOCALAPPDATA%\AccountingConverter`）にだけ保存されます。

## 3. 毎回の操作

画面は上から順に4つの手順になっています。

| 手順 | 操作 |
|---|---|
| ① 会社を選ぶ | 対象の会社を選びます |
| ② 仕訳データを選ぶ | 会計ソフトから出力したCSV / TXTをそのまま選びます（Excelで開いて保存し直さないでください） |
| ③ 保存先を選ぶ | 変換したCSVの保存先を選びます（既存のファイルは上書きしません） |
| ④ 実行前チェックと変換 | 確認が必要な項目があると、確認画面が開きます |

## 4. 確認画面の使い方

上部の1行に「**人が判断する回数（目安）**」と「**未確認の行**」が表示されます。
詳しい数え方は「▸ 件数の内訳と数え方」を開くと表示されます。

| タブ | 内容 |
|---|---|
| 科目 | 入力元の科目ごとに、JDLの科目を選んで「確認」にチェックします |
| 補助 | 親科目を確定すると、JDLの補助科目の候補が出ます。親科目が未確定の間は「親科目の確認待ち（登録要否は未判定）」と表示されます |
| 摘要 | JDLで保存できない文字や32文字を超える摘要の置き換えを確認します |
| 税区分 | 入力元の税区分ごとに、JDLでの扱いを確認します（別画面） |
| その他 | JDLに保持されない情報（弥生の付箋・生成元・部門など）の扱いを確認します |

- **まとめて確認**：「候補をまとめて確認…」では、名前が同じ候補だけ最初からチェックが入ります。
  言い換え・似ている候補はチェックされていません。選んだ内容は次の画面でもう一度確認してから反映します。
- **摘要の共通ルール**：ルールを承認 → 全件をプレビュー → 反映、の順に進みます。数字が変わる結果は使われません。
- **JDLに保持されない情報**（弥生）：項目ごとに「この会社での意味」を入力して確認します。確認した情報は
  **JDLには入らず**、変換したCSVと同じ場所に作られる記録ファイル（`〜.audit.json`）にすべて残ります。
  JDLの帳簿の上では見られなくなる点にご注意ください。
- **振替伝票入力行数**（弥生の会社のみ、「その他」タブ）：JDLの会社設定に表示されている「振替伝票入力行数」の数字を、
  そのまま入力します（最初は空欄で、アプリは数字を提案しません）。JDLは、この行数を超える伝票を**CSVの取込でも
  受け付けません**。超える仕訳は変換されず、分割するか、JDLで手入力が必要です（アプリは自動で分割しません）。
  入力しても超える仕訳が取り込めるようにはなりません。この数字は、実機で確認した範囲の判定にも使われます
  （確認済みの会社設定と一致するときだけ、実機で確認した税の書き方などを使えます）。
- **税区分の新しい候補**：弥生の「輸出売上」「課対仕入8%（軽）｜適格｜100%」「課対仕入10%｜区分記載｜80%経過措置」
  「対外仕入」には、実機で確認した書き方を候補として表示します。候補は自動では確定しません。ご自身で確認してください。
  「控除不可」と「決算仕訳」は、JDLでの書き方が未確認のため、変換できません（画面では「実機待ち」）。
- 「確認」にチェックした行だけが、画面下の「確認済み○件を保存」で保存されます。保存するときに、
  元のファイルと現在のJDL科目一覧をもう一度照合します。
- 「候補と根拠」ボタンで右側の説明を隠すと、表を広く使えます。境目はドラッグで調整できます。

## 5. 試用版でできないこと・注意点

- **JDL本番環境への取込はしないでください。**
- JDLの科目・補助科目の登録はアプリからはできません。JDLで登録してから「JDL科目一覧を更新」を使ってください。
- 弥生の次の税区分は、JDLでの表し方をまだ実機で確認していないため変換できません（画面では「実機待ち」と表示）：
  軽減税率8%、経過措置（80%など）、控除できない仕入など。
- 一部の複雑な仕訳（行数の多い複合仕訳など）は「仕訳の形が未検証」として変換されません。
- 弥生の決算仕訳は変換されません。
- 画面が小さい場合（1366×768で表示倍率125%など）は、一覧の表示行数が少なくなります。ウィンドウを最大化してください。
- 会社設定の画面の「対応内容を確認・変更」は、弥生の場合、保存済みの対応だけを表示します。新しい確認は手順④から行ってください。
- インターネットには接続しません。自動更新もありません。

## 6. 評価でお聞きしたいこと

試用後に、次の点を教えてください（顧客名・金額・摘要などは書かずに、画面名と件数でお願いします）。

1. 確認画面の各タブで、何を判断すればよいか分かりましたか。
2. 候補とその根拠は、判断の助けになりましたか。誤解しやすい表示はありましたか。
3. 1社の確認に、どのくらい時間がかかりましたか。
4. 「人が判断する回数」「未確認の行」などの件数は分かりやすかったですか。
5. 不具合やエラーメッセージ（画面名・操作・表示された文言）。

## 7. 困ったとき

- 画面が動かない・エラーが出た：表示されたメッセージと、どの画面で何をしたかを開発担当者へお知らせください。
- アプリを削除したい：`AccountingConverter` フォルダを削除します。会社設定も消す場合は
  `%LOCALAPPDATA%\AccountingConverter` フォルダも削除します（会社設定が消えるため、開発担当者に確認してから行ってください）。
